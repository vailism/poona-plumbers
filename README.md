# Poona Plumbers

Modern, premium website for Poona Plumbers - Residential & Commercial Plumbing Solutions in Pune.

## Features
- Pure HTML5, CSS3, and JavaScript (Zero dependencies)
- 10 core plumbing services with direct inquiry links
- Interactive appointment booking system with direct WhatsApp routing
- Community Plumbing Q&A forum with instant WhatsApp dispatch
- Responsive layout with mobile sticky call & WhatsApp bar
- Smooth animations (Scroll progress, number counters, floating badges, reveal effects)

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
- Lucide Icons
- Plus Jakarta Sans & Inter (Google Fonts)
